# 속편한 (Sokpyeon)

**동승자의 멀미를 미리 읽고, 운전자에게 대신 전하고, 실내 환경으로 줄여 주는 Pleos Connect 차량용 앱**

전기차·하이브리드의 회생제동 '울컥', 급가속·급제동, 급커브를 차량 신호로 감지해 동승자의 멀미 위험도를 계산합니다.
흔들림이 쌓인 순간에만 잠깐 '멀미'라는 말을 듣고, 동승자 대신 운전자에게 부드러운 음성 안내를 전하며, 바깥 공기·실내 조명을 바꿉니다.
내비를 화면에 띄워 둔 채로도 뒤에서 계속 동작합니다.

---

## APK

- 위치: [`apk/`](apk/) 폴더
- release 빌드, 설치 후 Pleos 앱 목록에서 **속편한** 실행

## 테스트 환경

| 항목 | 내용 |
|---|---|
| 에뮬레이터 | Pleos Connect Emulator **v2.1.0** (Android API 34, Automotive) |
| AVD 설정 | Cold boot, RAM 4GB (Pleos 개발자 가이드 기준) |
| 개발 환경 | Android Studio, Kotlin, Jetpack Compose, minSdk 28 |
| 사용 SDK | Pleos Vehicle 2.3.2, FusedLocation 1.1.3, SpeechToText 3.3.1, TextToSpeech 3.3.1 |

### 필요한 설정

1. **마이크(음성 인식 시험 시)**: 에뮬레이터 Extended Controls → Microphone → **Enable Host Microphone Access** 켜기
2. **권한**: 첫 실행 시 뜨는 권한 요청(차속, 위치, 알림)을 모두 **허용**
3. 앱은 **Pleos 앱 목록에서 실행**해 주세요. (테스트 중 앱 화면이 보이지 않으면 `adb shell am force-stop com.sokpyeon.app` 후 앱 목록에서 다시 실행)

## 실행·시연 방법

에뮬레이터에서는 차를 실제로 달리게 할 수 없어, **정체 구간 주행 데이터를 재생하는 시연 기능**을 넣었습니다.
실제 차량에서는 버튼 없이 차속·브레이크·기어·위치 신호를 그대로 읽습니다.

| 동작 | 방법 |
|---|---|
| 주행 재생 시작/정지 | 왼쪽 위 **로고를 길게 누르기** (약 80초: 정체 구간 가다 서다 → 나들목 굽은 길 → 정차) |
| 초기화 | 로고를 **두 번 누르기** |
| 동승자 멀미 신호 | 화면의 **멀미 나요** 버튼, 알림의 **멀미 나요** 버튼, 또는 듣는 중에 "멀미"라고 말하기 |
| 내비와 함께 쓰기 | 재생을 시작한 뒤 하단 바의 내비로 이동 → 뒤에서 감지·음성 안내 계속 |

재생 결과(기본 설정 기준): 회생제동 울컥 4회, 급가속 1회, 급제동 1회, 급커브 2회

## 주요 기능

- **승차감 판단**: 차속(0.2초 간격)으로 급가속·급제동을 감지하고, 브레이크 페달을 밟지 않은 강한 감속을 **회생제동 '울컥'**으로 구분. 위치의 진행 방향 변화로 **급커브** 감지
- **멀미 위험도(0~100)**: 동승자 민감도(거의 안 해요·가끔 해요·자주 해요)를 반영
- **조건부 듣기**: 위험도가 높을 때만 30초간 듣고, '멀미'·'휴게소'·'괜찮아' 같은 정해진 단어만 확인. 대화 내용은 화면에 보여 주거나 저장하지 않음
- **단계별 대응**: 위험도 50 이상 → 바깥 공기·실내 조명(밝기는 올리지 않고 색만) / 70 이상 → 원인별 음성 안내 / 90 이상 1분 또는 멀미 신호 2회 → 휴식 제안
- **잔소리 방지**: 같은 종류 안내는 10분에 한 번, 안내끼리 최소 60초 간격, 주차 중에는 운전 안내 없음
- **세 화면**: 출발 전 준비 → 주행 중(최소 정보) → 주행 후 돌아보기(속도 흐름 그래프, 흔들림·안내 기록)
- **백그라운드 실행**: 포그라운드 서비스로 내비 화면 위에서도 동작, 상시 알림에 '멀미 나요' 버튼
- **라이트·다크 테마**: Pleos UI 디자인 가이드의 색상·글꼴(Asta Sans) 기준

## 코드 구조

`app/src/main/java/com/sokpyeon/app/MainActivity.kt`

| 구성 | 역할 |
|---|---|
| `SokpyeonEngine` | 판단 엔진: 차량 신호, 감지, 위험도, 음성 듣기·안내, 공조·조명 (화면과 분리) |
| `SokpyeonService` | 포그라운드 서비스: 엔진을 뒤에서 계속 실행, 알림 '멀미 나요' 버튼 |
| `MainActivity` | 화면(Jetpack Compose): 엔진 상태 표시 |

## 개인정보

모든 판단은 차량 안에서 처리하며(On-device), 별도 서버로 데이터를 보내지 않습니다. 음성 인식은 ON_DEVICE 모드를 사용합니다.
